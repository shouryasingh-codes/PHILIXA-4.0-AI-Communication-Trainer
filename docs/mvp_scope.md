# PHILXA 4.0 MVP Scope

## One-line Definition

PHILXA 4.0 MVP is a Corporate World communication trainer where a user enters a live office conversation, responds to workplace prompts, and receives clear scores plus coaching feedback on communication quality.

## Primary User

A learner who wants to practice workplace communication in a controlled office-meeting environment before using those skills in interviews, internships, or real corporate conversations.

## MVP Room

Only one room is included in the MVP:

- Corporate World
- Team discussion / office meeting
- Three AI roles: Boss, Manager, and Colleague
- One user participating as an employee or team member

## Core Flow

1. The office room starts with a short AI-to-AI conversation.
2. The user enters and replies to the current discussion.
3. AI roles respond in a natural meeting order.
4. The system stores each turn as structured conversation data.
5. The user's answer is scored.
6. The system gives one strong point, one weak point, one exact correction, and one improved rewrite.
7. The session ends with a concise summary.

## Scoring Areas

The MVP evaluates:

- Confidence
- Grammar
- Clarity
- Structure

Technical explanation can remain a secondary score when the answer is work-specific, but it should not block the MVP.

## In Scope

- Corporate World room only
- One base office-meeting scenario
- Boss, Manager, and Colleague personalities
- Structured turn storage
- Short-term conversation memory
- User answer scoring
- Feedback generation
- Session summary
- Simple Streamlit or Gradio UI

## Out of Scope

- Multiple rooms
- Interview, sales, campus, or friendship scenarios
- Long-term user profile memory
- Voice input or speech analysis
- Advanced analytics dashboards
- Multi-user live rooms
- Production authentication
- Complex deployment infrastructure

## Success Criteria

The MVP is successful when a user can complete one office conversation session and clearly understand:

- what they said well
- what needs improvement
- how to rewrite their answer better
- what to practice next
